# 🖼️ Image Search App

A responsive Image Search App built with **HTML, CSS, and JavaScript** using the **Unsplash API**.

Users can search for images by keyword and view the results in a responsive image gallery.

## 🚀 Features

- 🔎 Search images by keyword
- 🖼️ Display multiple image results
- 🎨 Responsive grid gallery
- ✨ Image hover effects
- ⏳ API loading state
- ⚠️ Error handling
- 📱 Mobile responsive design
- 🌐 Unsplash API integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Unsplash API
